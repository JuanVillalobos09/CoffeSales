CoffeeSales-Analisis

Contexto del Proyecto
-Este proyecto es una aplicación desarrollada en Java diseñada para procesar, analizar y extraer métricas clave a partir de un gran volumen de datos transaccionales de una cadena de cafeterías. El sistema identifica patrones de ventas, rendimiento de productos y picos de demanda.

Stack Tecnológico
1. Lenguaje: Java (JDK 11+)
2. Gestor de dependencias: Maven 
3. Librerías/Tecnologías: Apache Commons CSV (para lectura de datos), Java Streams API (para procesamiento de datos).

Principales Hallazgos 
1. Horas Pico: El sistema detectó que el 60% de las ventas ocurren entre las 7:00 AM y las 10:00 AM.
2. Rendimiento de Producto: El 'Caramel Macchiato' es el producto con mayor volumen de ingresos sostenidos.
3. Tendencias: Módulo de estacionalidad calculó un aumento del 40% en bebidas frías durante el tercer trimestre.

Cómo ejecutar este proyecto
1. Clona el repositorio.
2. Instala las dependencias.
3. Ejecuta el notebook principal ubicado en la carpeta.
